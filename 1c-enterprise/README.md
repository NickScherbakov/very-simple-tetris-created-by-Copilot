# Tetris для 1С:Предприятие

В каталоге `./1c-enterprise` находится исходный набор для переноса текущего проекта в экосистему **1С:Предприятие 8.3**.

## Что входит

- `src/CommonModules/TetrisGameLogic/Ext/Module.bsl` — поле, фигуры, столкновения, повороты, уровни, очки
- `src/CommonModules/TetrisAiCoach/Ext/Module.bsl` — адаптивный тренер, подсказки, подбор фигур, AI-vs-AI эвристика
- `src/CommonModules/TetrisEconomy/Ext/Module.bsl` — TetriCoins, бонусы, ставки, темы, турниры, достижения
- `src/CommonModules/TetrisReplay/Ext/Module.bsl` — запись партий, экспорт/импорт повторов, challenge-сценарии
- `src/CommonModules/TetrisSessionManager/Ext/Module.bsl` — orchestration слой для одиночной игры, AI-матчей и турниров
- `src/CommonForms/TetrisGame/Ext/Form/Module.bsl` — модуль формы с таймером и обработчиками команд

## Аналоги возможностей веб-версии

| Веб-версия | Аналог в 1С |
|---|---|
| Canvas и DOM UI | Общая форма с таймером, таблицей поля и командами формы |
| LocalStorage | Хранилище настроек, регистры сведений или константы конфигурации |
| AI Insight | Поле подсказки и модуль `TetrisAiCoach` |
| AI vs AI / Tournament | `TetrisSessionManager` + `TetrisEconomy` |
| TetriCoins / Shop / Achievements | `TetrisEconomy` |

| Мультиязычность | Стандартная локализация метаданных 1С |
| PWA / offline | Тонкий, веб- или мобильный клиент 1С |

## Рекомендуемая конфигурационная обвязка

Для полноценного внедрения в конфигурацию 1С рекомендуется создать:

- **Общую форму** `TetrisGame`
- **Регистр сведений** для баланса, рекордов, достижений, купленных тем и повторов
- **Справочник** команд для командного турнира
- **Общий модуль** запуска игры из интерфейса

## Ожидаемые элементы формы

Модуль формы использует следующие элементы:

- `FieldView` — табличное представление поля 10x20
- `NextPieceView` — текстовый предпросмотр следующей фигуры
- `StatusLabel` — счет, линии, уровень, баланс
- `HintLabel` — подсказка AI
- `ModeLabel` — текущий режим
- команды формы: `StartCommand`, `PauseCommand`, `LeftCommand`, `RightCommand`, `RotateCommand`, `DownCommand`, `DropCommand`, `AiMatchCommand`

## Как использовать

1. Создайте в конфигурации общие модули и форму с указанными именами.
2. Перенесите исходники `.bsl` в соответствующие объекты EDT / Designer.
3. Добавьте таймер формы с интервалом `Session.GameState.DropInterval`.
4. Свяжите команды формы с экспортными процедурами модуля формы.
5. При необходимости перенесите состояние из внутренних структур в регистры сведений.

## Что уже реализовано в исходниках

- классический Tetris 10x20 с 7 тетромино
- очки, уровни, очистка линий, hard/soft drop
- призрачная фигура
- адаптивный подбор фигур и текстовые подсказки
- AI-vs-AI планировщик ходов
- TetriCoins, ежедневный бонус, магазин тем, ставки и турнирный банк
- повторы и challenge-цели

## Ограничения

В репозитории хранится **исходный код и архитектура** для 1С-версии. Готовый бинарный `.epf`/`.cf` не добавлялся, потому что его сборка требует локального Designer/EDT и установленной платформы 1С.
